# pie-codes
Codes related to the personal ionospheric experiment (PIE). 
Note : Usage of the code and data permitted ONLY for scientific studies involving the ionosphere, magnetosphere or space physics.

Data collected from PIE are available at https://zenodo.org/doi/10.5281/zenodo.13119736
Description of PIE is available at https://arxiv.org/abs/2409.07758 (also at https://doi.org/10.22541/essoar.172612553.32913210/v1)

PIE Summary paper presented at the XXXVIth URSI General Assembly and Scientific Symposium (URSI GASS 2026) available at https://doi.org/10.46620/URSIGASS26/IVTK6571
